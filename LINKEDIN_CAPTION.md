# LinkedIn Caption - Body Measurement System

## Option 1 (Technical):
🎯 Built an AI-powered body measurement system using Computer Vision and Deep Learning!

The system uses HMR (Human Mesh Recovery) to estimate 3D body mesh from a single camera image, extracts 9 anthropometric features, and predicts height & weight using Ridge Regression trained on real measurements. Implemented smart photo detection to reject 2D images and only accept real people.

Tech Stack: Python, TensorFlow, OpenCV, SMPL, Flask | Accuracy: ±2.6 cm height, ±1.3 kg weight
